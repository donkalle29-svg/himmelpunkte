# Himmelpunkte

Ein eigenständiges, browserbasiertes Multiplayer-Kartenspiel mit Echtzeit-Verbindung.

## Lokal starten
1. Node.js installieren (https://nodejs.org).
2. Im Projektordner `npm install` ausführen.
3. `npm start` ausführen.
4. Im Browser `http://localhost:3000` öffnen.

Für Freunde außerhalb deines WLANs muss der Server auf einem Hosting-Dienst (z. B. Render) veröffentlicht werden. Danach können alle über denselben Link und den Raumcode beitreten.

## Hinweis zum Spielstand
Diese erste Version ist ein spielbarer Multiplayer-Prototyp. Bei einem Verbindungsabbruch wird eine laufende Runde pausiert; dauerhaftes Speichern und Wiederbeitreten sind noch nicht enthalten.
